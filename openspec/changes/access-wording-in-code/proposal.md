## Why

Comments and docstrings in the code and the shipped configuration still
describe the workspace as "conscious", ground the resting access rate in the
P3b, and call the language organ's abliteration a matter of "sovereignty".
The paper of record describes access, not consciousness, grounds arousal in
the adaptive-gain account of the locus coeruleus, and gives the abliteration
a plain purpose. A reader of the code should meet the same account.

## What Changes

- Comment and docstring wording only, in `kaine/**` and `config/**`: access
  terms in place of consciousness terms, no P3b grounding, and the plain
  purpose of abliteration.
- No identifiers, keys, values or logic change.

## Capabilities

### Modified Capabilities

- `documentation-consistency`: code comments follow the paper's terms.

## Impact

- About 22 files, comments only. No behaviour change.
