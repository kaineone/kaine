## Why

The research paper has a new title: *KAINE: A Modular Cognitive Architecture
with a Predictive Global Workspace*. Its old title was *KAINE: A Continuously
Running Predictive Global Workspace for Synthetic Minds*, and the italic
subtitle line is gone. The book still cites the paper by its old title.

## What Changes

- `docs/01-what-kaine-is.md` cites the paper by its new title.
- No other page, spec, code path or citation file in this repository names the
  paper's title or subtitle, so nothing else changes. Archived OpenSpec changes
  are historical and are left as written.

## Impact

Documentation only. No behavior, configuration or test changes.
