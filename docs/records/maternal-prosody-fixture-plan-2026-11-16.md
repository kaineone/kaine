# Maternal prosody fixture plan: deterministic smoke fixtures

Date: 2026-11-16

Status: plan only. No fixture files, source code, tests, manifests, generated audio, or text files are changed by this document. It defines deterministic smoke fixtures for `tools/maintainer/check_maternal_prosody.py` and their expected CLI output snapshots.

## Scope

This plan covers the prose/text checker only. It does not render, decode, or validate audio. Audio-side smoke gate S5 remains separate and is defined in `docs/records/maternal-voice-sam-render-plan-2026-11-16.md`.

Checker under test:

- `tools/maintainer/check_maternal_prosody.py`
- Modes: `--text`, `--file`, `--texts`, and stdin
- Exit statuses: `0` = all checked texts pass, `1` = at least one checked text fails, `2` = no input

Default thresholds:

- `MAX_SYLLABLE_DENSITY = 1.8`
- `MAX_SYLLABLES_PER_WORD = 2.0`
- `MIN_TRANSIENT_REDUCTION = 0.55`
- `MAX_READABILITY = 40.0`

## Proposed fixture location

Use a data-only directory, independent of the Python package:

```text
tests/fixtures/maternal_prosody/
```

All fixture files are ASCII, use LF line endings, and are terminated by exactly one `\n` unless explicitly marked as empty stdin. The `<FIXTURE_ROOT>` placeholder below expands to `tests/fixtures/maternal_prosody`.

Expected output labels are the path passed on the command line. In the snapshots below, `<FIXTURE_ROOT>` stands in for that directory; a test may instead normalize that label with a regex or fixture path.

## Single-text file fixtures

Generate each file with the exact command shown. Do not edit the generated bytes by hand.

### 1. Valid smoke fixture

File: `valid-90-ma.txt`

Preparation:

```bash
python -c "print('ma '*90)" > tests/fixtures/maternal_prosody/valid-90-ma.txt
```

Expected checker behavior:

```bash
python tools/maintainer/check_maternal_prosody.py --file tests/fixtures/maternal_prosody/valid-90-ma.txt
```

Expected snapshot:

```text
tests/fixtures/maternal_prosody/valid-90-ma.txt: ok=True density=1.00 reduction=1.00 readability=30.9
```

Expected exit status: `0`

### 2. Invalid by readability

File: `invalid-readability-fox.txt`

Preparation:

```bash
printf '%s\n' 'The quick brown fox jumps over the lazy dog.' > tests/fixtures/maternal_prosody/invalid-readability-fox.txt
```

Failure reason: density and transient reduction are within range, but readability `94.3 > 40.0`.

## TOML aggregate fixture

File: `valid-invalid-mix.toml`

Preparation, deterministic generation (do not hand-maintain the 90-token line):

```bash
python - <<'PY'
from pathlib import Path
out = Path("tests/fixtures/maternal_prosody/valid-invalid-mix.toml")
valid = "ma " * 90
items = [
    ("valid-90-ma", valid),
    ("invalid-readability-fox", "The quick brown fox jumps over the lazy dog."),
    ("invalid-transient-ba", "ba ba ba"),
    ("invalid-density-super", "supercalifragilistic expialidocious"),
]
lines = []
for item_id, text in items:
    escaped = text.replace("\\", "\\\\").replace('"', '\\"')
    lines.append(f'[[item]]\nid = "{item_id}"\ntext = "{escaped}"\n')
out.parent.mkdir(parents=True, exist_ok=True)
out.write_text("\n".join(lines), encoding="utf-8", newline="\n")
PY
```

Expected command:

```bash
python tools/maintainer/check_maternal_prosody.py --texts tests/fixtures/maternal_prosody/valid-invalid-mix.toml
```

Expected snapshot:

```text
valid-90-ma: ok=True density=1.00 reduction=1.00 readability=30.9
invalid-readability-fox: ok=False density=1.22 reduction=0.63 readability=94.3
invalid-transient-ba: ok=False density=1.00 reduction=0.50 readability=119.2
invalid-density-super: ok=False density=6.50 reduction=0.62 readability=-345.1
```

Expected exit status: `1`

Interpretation: exactly one of four items passes; a mixed fixture is suitable for testing both aggregate pass detection and per-item diagnostics.

## No-input snapshot

No fixture file is needed. The empty-stdin case exercises CLI exit `2`.

Command:

```bash
printf '' | python tools/maintainer/check_maternal_prosody.py
```

Expected snapshot:

```text
no input
```

Expected behavior: `no input` is written to stderr; stdout is empty.

Expected exit status: `2`

## Assertion checklist for future tests

A future smoke or test implementation using these fixtures should assert at least:

1. `valid-90-ma.txt` yields exit `0`, `ok=True`, and the exact metric line in its snapshot.
2. Each invalid fixture yields exit `1`, `ok=False`, and a metric line matching its snapshot.
3. The invalid fixtures fail for the intended reason:
   - `invalid-readability-fox.txt`: `readability > 40.0`
   - `invalid-transient-ba.txt`: `reduction < 0.55`
   - `invalid-density-super.txt`: `density > 1.8`
4. `valid-invalid-mix.toml` yields exit `1` and four per-item lines in item order.
5. Empty stdin yields exit `2`, stderr `no input`, and empty stdout.
6. Running any checker invocation does not modify source files, tests, manifest, or generated audio.
